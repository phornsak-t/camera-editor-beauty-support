# Camera Editor Beauty: AI Photo — Privacy & Support

Public, static privacy-policy and support pages for the iOS app by Phornsak Tibyakad.

- Privacy Policy: https://phornsak-t.github.io/camera-editor-beauty-support/privacy.html
- Support: https://phornsak-t.github.io/camera-editor-beauty-support/support.html

Publish from the root of the `main` branch using GitHub Pages. No build dependencies,
analytics scripts, cookies added by this website, or third-party fonts are used.

Do not submit sensitive personal information or private photos in issues.

The website policy mirrors the bundled app policy, with full store branding and a
contact section. Review it when the app's actual data practices or SDK settings change.
